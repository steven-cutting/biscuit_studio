# The platform upstream

This page will describe the hub, `steven-cutting/biscuit_games`, as the upstream this
repository consumes: the package that ships the design system, the three Allium modules
that specify how every surface looks, is worked and what it owes, and the pages that
record the aesthetic and the character. It will carry the only cross repository links in
the handbook, each a whole page address rather than a fragment.
