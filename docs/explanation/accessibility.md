# Accessibility

This page will explain the obligations the site inherits from the platform: the
legibility floor in every combination of theme and high contrast, colour never carrying
meaning alone, keyboard operation with visible focus, motion that stops when the device
prefers reduced motion, and what the embedded viewer must do about auto rotation, its
background and pinch zoom so it breaks none of them.
