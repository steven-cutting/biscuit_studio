# Decision 0009: No component workshop yet

This record will state that the studio installs no component workshop and no visual
review service in its first release, because it authors no shared component and mounts
the platform's instead. It will give what would reopen the question, a component of the
studio's own such as the ported viewer, and the consequence that the coverage floor and
the tests carry the evidence alone.
