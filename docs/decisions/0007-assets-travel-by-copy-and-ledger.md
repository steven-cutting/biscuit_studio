# Decision 0007: Assets travel by copy and ledger

This record will state that a finished asset reaches the hub or a game by copy, recorded
in a ledger a consumer's gate can verify, never by a package or a submodule. It will give
the interim procedure until the ledger tooling exists, the ticket that designs the
ledger, and the consequence that every copy names the studio commit and the sha256 of
the bytes beside it.
