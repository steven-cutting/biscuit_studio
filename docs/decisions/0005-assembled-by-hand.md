# Decision 0005: Assembled by hand, not rendered from the template

This record will state that the toolchain was assembled by hand from the hub, the first
game, the template and the tooling repository, each file with its source recorded, rather
than rendered by Copier from the template. It will give the reason: the template renders
only a game, and a render whose handbook pages were deleted breaks on its next update
because the manifest is rendered again.
