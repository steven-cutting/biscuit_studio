# Troubleshooting

This page will collect the failures people meet and what each means: a package install
that returns not found because the token lacks the packages scope, a checkout holding
pointer text where the model should be, a gate that reports a recipe changed the
worktree, a manifest that disagrees with a file under `assets/`, an image the checker
refuses for its metadata, and a page the contract reports unreachable.
