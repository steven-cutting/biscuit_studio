# Terminology

This page will define the words this repository uses precisely and refuses to use
loosely: the hub and the platform package, a game as a consumer, the studio, the approved
model and its native sources, the viewer, a render and an export, a blob against an LFS
object, the manifest and its ledger fields, a lane ticket, and the difference between a
promotion and a handover.
