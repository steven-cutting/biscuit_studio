# Decision 0004: A project Pages site

This record will state that the site is a project Pages site at the repository's own
address under the owner's GitHub Pages domain, built with a base path equal to the
repository name, and that the custom domain stays with the first game. It will give the
consequence for links and the base path the build and the preview must share, and why a
user site was not chosen.
