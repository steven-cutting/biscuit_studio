# Agent contract

This page will describe the agent contract and how it is checked: `AGENTS.md` as the
single source of truth with its required guidance phrases and word floor, the two thin
adapters the validator compares byte for byte, the eight skills under `.agents/skills/`
with their frontmatter rules, the bridges under the two provider directories whose body
must be exactly the canonical sentence, and the one tolerated settings file.
