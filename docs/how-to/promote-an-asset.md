# Promote an asset

This page will be the interim procedure for moving a finished asset into the hub or a
game before the ledger tooling exists: confirm the hub's rules permit it, copy the bytes
by hand, record the studio commit and the sha256 beside the copy in the receiving
repository, and write the item into the hub handover page so what the consumer owes is
written down rather than remembered.
