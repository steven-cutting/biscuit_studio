# Documentation contract

This page will be the contract every page under `docs/` obeys and the validator enforces:
the six manifest keys, frontmatter equal to the manifest entry including list order, a
single level one heading equal to the title, at least forty words of substance, no
unfinished markers or template delimiters, relative links resolved with exact case, and
every page reachable from the documentation map.
