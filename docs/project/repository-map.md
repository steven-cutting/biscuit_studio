# Repository map

This page will walk the tree directory by directory: the site under `src/` and `static/`,
the tests under `tests/`, the imported assets under `assets/` with their manifest, the
handbook under `docs/`, the agent contract and its skills, the scripts the recipes call,
and the configuration files at the root. For each it will say which ticket or lane owns
the path and which tool reads it.
