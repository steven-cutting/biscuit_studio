# Configuration

This page will describe each configuration file at the root and what it controls: the
two manifests and their lockfiles, the Svelte, Vite and TypeScript configuration, the
ESLint and Prettier settings, the hook gate and its mutating counterpart, the editor and
Markdown settings, the link checker, the Git attributes that name the LFS patterns, and
the one exclusion set written into six of them.
