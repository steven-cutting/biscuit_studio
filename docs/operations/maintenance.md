# Maintenance

This page will be the maintenance routine: the monthly dependency review and lockfile
raise, the online link check run by hand, the review of the platform package's changelog
before raising its pin, the periodic confirmation that the deployed site still serves the
viewer and the model with their recorded checksums, and when the model's rebuild chain in
the picture repository needs attention.
