# Purpose and scope

This page will say what the studio is for and what it is not. It is the Biscuit Games
repository where the platform's graphical assets are developed, the poseable model, the
renders and exports made from it and the two dimensional illustrations, together with a
static site that shows them. It consumes the platform package as a game does and nothing
depends on it; finished assets leave by copy, never by import.
