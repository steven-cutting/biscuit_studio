# Decision 0002: The hub is upstream

This record will state that the hub is the source of truth for shared behaviour and
changes first: the aesthetic, the character, the tokens and the specifications are
decided in the hub, the studio consumes the platform package as a game does, and where
the studio needs the hub to permit something it forbids today, the hub's page and
decision record change before anything here relies on it.
