# Commands

This page will list every `Justfile` recipe with what it runs and when to reach for it:
the setup recipes, the develop recipes, the format and fix recipes, each check recipe in
the order `just check` runs them, the documents recipes, the two asset recipes that read
and write the manifest, and the model rebuild recipe that is never part of the gate.
